# sideline icon

`icon.svg` is hand-authored SVG, not generated artwork, so there is no
generation prompt to preserve.

A play-diagram fragment: scattered position marks above a heavy rule, and one
mark alone below it. The rule is the sideline; the mark below it is the player
who is out. The separation carries the idea, so it survives at 32 pixels.

Palette matches the project family: tile `#173e39`, marks `#f4f7eb`, the
sidelined mark `#d4b660`. The marks are drawn as geometry rather than
characters; keep them scattered at differing heights so they do not read as
letters on a baseline.
